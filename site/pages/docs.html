Documentation

One source, several doors.

The documentation lives in the repository, beside the code it describes, so that a change to one fails the build when it contradicts the other. This page is an index into it — not a second copy of it.

Links resolve to main on GitHub. Markdown links, prose file paths, and every example are checked automatically on each run; a document that drifts out of the index is reported as orphaned.

Install

The package.

npm install @echelon-foundry/typescript-wasm-kernel

The published name is unchanged. Limen is the product name; no exported symbol, file path, or protocol type was renamed, so there is nothing to migrate — no deprecation, no alias, no codemod.

Requires Node 22 or newer to build and test, TypeScript 5.9 or newer for the types, and a browser with ES2022 modules, fetch and AbortController. It has no runtime dependencies. Versioning is semver and currently 0.x, so the protocol may still change in a minor release.
