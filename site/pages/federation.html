The source module depends on the target for this proof, so startAll() must activate the target first. The target accepts only the request contract. The source accepts only the result contract. Both F# modules independently decode JSON into local typed records before any value becomes authoritative state.

What this establishes

Federation is now demonstrated across real F# WebAssembly runtimes.

This is an existence proof, not a performance claim. The main Limen product application remains one F# engine; this sibling proof demonstrates that independently loaded F# WASM state systems can compose without weakening the Limen boundary.
